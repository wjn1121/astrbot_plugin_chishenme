## 图片建议

- 格式：JPG 或 PNG
- 尺寸：建议 600×400 左右，过大可能影响发送速度
- 来源：可从 Unsplash、Pexels 等免费图库下载，或用自己拍摄的美食照片

## 扩展

1. 将新图片放入此目录
2. 在 `data/foods.json` 中添加对应条目
3. 重载插件即可生效
